# AI Resume Analyzer Frontend

A ready-to-run React + Vite frontend for the B.Tech final-year project:
AI-Based Resume Screening & Job Recommendation System.

## Pages
Home, Register, Login, Dashboard, Upload Resume, Analysis Result,
My Skills, Recommended Jobs, Skill Gap Analysis, Profile, Admin Dashboard.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

This version is frontend-only and uses dummy data. Backend, MySQL and ML APIs can be connected later.
